# 実装状態

この一覧はローカル実装と外部サービスの検証を区別します。外部認証情報は用意されておらず、サービスを公開していません。

| 機能 | 状態 | 根拠・制約 |
|---|---|---|
| 全指定ページ・テーマ・mobile | 実装・検証済み | ビルド、E2E、ブラウザ表示 |
| Monaco編集・実行・提出・解説 | 実装・検証済み | 実ブラウザのNumPy実行、エラー、結果保存 |
| 180問・30概念 | 実装・検証済み | native 1,440ケース |
| ブラウザ実行120問 | 実装・検証済み | 実際のPyodide経由で480ケース合格 |
| Deep Dive 12課題 | 実装・検証済み | 確定的採点と保存、各課題のAPIテスト |
| 読解3プロジェクト・24設問 | 実装・検証済み | 3/4/5ファイル、各CLI・推論の実行 |
| ローカルゲスト・SQLite保存 | 実装・検証済み | HttpOnly Cookie、履歴分離、再開 |
| IndexedDB下書き・revision同期 | 実装・検証済み | unit/API/E2E。競合時はローカルを保持 |
| 暫定進捗・正式認定の分離 | 実装・検証済み | クライアント結果でIndependent認定不可 |
| 段階進行・復習・Daily/Custom | 実装・検証済み | 異なるファミリー・ヒント・variantと復習のテスト |
| 履歴・Analytics・連続日数・目標 | 実装・検証済み | 実データのみ、未測定と0を区別 |
| Supabase Auth・Google・メール | 外部設定待ち | UI/API/JWT検証実装、実OAuthとメール配信は未検証 |
| PostgreSQL migration・RLS | 実装済み・実接続未検証 | private schema、行所有者SELECT、更新はAPIのみ |
| Modal隔離実行・正式採点 | 外部設定待ち | provider/Worker/比較器実装。実Sandboxの制限確認は未実施 |
| 永続ジョブ・lease・cancel・rate limit | 実装済み・一部未検証 | lease・状態・同時実行制約はローカル検証。Modal連携は未検証 |
| CI / OpenAPI / API型 | 実装済み・一部未検証 | コマンドはローカル実行、GitHub上のCIは未実行 |
| Guided固定コードの編集制限 | 未実装（任意要件） | 初期コードは全体を編集可。Undo/Redo・初期コード追加で回復可能 |
| 別アカウントへの履歴自動統合 | 未実装（初期版で省略可） | 上書きせず、Identity Linkingと明示的な既存ログインを用意 |
| サーバー未設定時のPyTorch | 利用不可 | 503と設定案内。成功の代替値を返さない |
| 本番公開 | 未実施 | ユーザー指定によりpush・公開なし |

優先する次の作業は、専用Supabase・Modal環境の実接続検証、専用実行オリジンへの配備確認、教材の教育的レビュー、Guided編集範囲制御です。検証が済むまでは本番運用可能と判断していません。
