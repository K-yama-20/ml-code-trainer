# Drillのエディタ・Python実行・教材検証

## エディタ

従来は、学習者が空欄を消すとReact側が `___` を補い、controlled valueとMonacoの内容が食い違っていた。MonacoのReactラッパーは差を文書全体の置き換えで反映する。固定コードに触れた場合にも、独自の復元処理が文書を書き直していた。どちらもカーソル移動や文字の復活につながっていた。

DrillではMonacoモデルが編集を持つ。問題の初期化時に固定の前後と解答を分け、編集の開始・終了位置をモデルのオフセットから求める。固定位置をまたぐ操作は編集トランザクションの適用前に止める。Undo/RedoはMonaco標準の履歴を使う。自動保存と採点には解答だけを送る。固定入力のない旧バージョンでは、既存の関数全体を編集できる仕様を維持する。初期テンプレートの空欄マーカーは教材の互換性のために内部で解釈し、画面に描画しない。空の解答も空のまま保存する。Partialの代入行は、複数文の解法も書けるよう編集ブロックに含め、初期カーソルを代入式の右側に置く。

## 実行の分離

以前はRunごとに隔離iframeとWorkerを作り、実行後に破棄していた。次の実行でも、Pyodide初期化、パッケージ初回ロード、Python側の採点コード読み込みが必要だった。

現在はDrillを開いたときにブラウザPythonの準備を始める。基本的なPython・NumPy・Pandasの処理は、同じ隔離Workerで実行する。ケースごとの名前空間は独立している。ファイルやグローバル状態に触れ得るコードは実行後にWorkerを破棄する。タイムアウトや中止でもWorkerを交換する。ASTの再利用条件によって正誤の基準は変わらない。サーバーの正式採点には従来の経路を使う。

## Chromiumでの実測

同じChromium、実行コード、公開ケースで各6回実行した。修正前欄は、1回終わるたびにWorkerを破棄する旧方式を現行の計測用コードで再現した値。キャッシュ設定は両条件で同じ。p50とp95は2〜6回目のクリックから結果の可視確認まで。5サンプルのp95は観測した最大値で、Playwrightの可視確認の待ちも含む。

| 問題 | 旧方式 p50 / p95 | 再利用 p50 / p95 | 再利用方式の初回 |
| --- | ---: | ---: | ---: |
| PY01-03 Pythonの辞書 | 5,057 / 5,161 ms | 130 / 142 ms | 5,092 ms |
| NP05-01 NumPyの行平均 | 10,221 / 11,248 ms | 145 / 153 ms | 7,132 ms |

| 計測箇所 | Python | NumPy |
| --- | ---: | ---: |
| 旧方式のWorker生成中央値 | 1.8 ms | 1.6 ms |
| 再利用方式の初回Pyodide初期化 | 5,178 ms | 4,134 ms |
| 同じ初回の実行用コード準備 | 176 ms | 187 ms |
| パッケージ初回ロード | なし | 2,482 ms |
| 再利用後の学習者コード実行 p50 | 0.5 ms | 1.5 ms |
| 再利用後の公開ケース全体 p50 | 3.1 ms | 9.5 ms |
| 再利用後のJS結果比較 p50 | 0.1 ms | 0.1 ms |
| 初回の下書き同期API | 31.8 ms | 24.6 ms |

NumPyの初回実行では公開ケース全体に141 msかかった。2回目以降の5回はパッケージ再ロード0回、追加API通信0件だった。公開ケースだけのRunを測定した値で、サーバーでの正式採点は別経路。ネットワークや端末により初回の読み込みは変動する。

再計測は `npx playwright test -c playwright.runtime.config.ts`。今回の生データは `artifacts/drill-runtime-comparison.log`。

## 自動検証

教材検証は既存CIで実行される。180問×2 seedの完成コード、1322件の模範解答ケース、360件の代表誤答、12件のDeep Dive、3つのCode Readingプロジェクトを対象とする。原本からの再生成とコミット済み教材の一致、問題ID・バージョン・seedの組も確認する。

API 93件、フロントエンド18件が合格した。APIの外部連携テスト2件は環境条件によりスキップした。TypeScript、lint、本番ビルド、公開データのセキュリティ検査も通過した。Chromiumで空欄を保ったままの編集、Undo/Redo、コピー・複数行貼り付け、IME合成入力、採点、下書き復元を確認した。Workerの再利用、名前空間と一時ファイルの分離、タイムアウトからの復旧、実行中の問題切り替えも確認した。Pyodideではブラウザ実行対象120問の模範解答を検証した。旧バージョンの提出・中断と再開、現行のscikit-learn穴埋め、21問連続提出と履歴21件の保存もChromiumで確認した。

実機の日本語入力、サーバーSandboxの起動と通信時間は、別環境で確認する必要がある。
